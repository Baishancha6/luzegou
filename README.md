# luzegou
Luzegou is an e-commerce intelligent assistant, a multi-agent system orchestrated with LangGraph.

1.langgraph orchestration
Orchestrate three types of agents using LangGraph Supervisor: routing agent, multi-intent agent, and six specialized agents (shopping guidance, comparison, discounts, order placement, logistics, etc.). The multi-intent agent acts as the supervisor, while the specialized agents serve as workers. Based on dependency relationships, perform sequential loops and parallel sends, collect results, and aggregate them.
